1. Statistical IQR Detector
Weight: 25%

Calculates first quartile (Q1), third quartile (Q3), and the Interquartile Range (IQR = Q3 - Q1) on key numerical distributions: amount, amount_deviation, hourly burst frequency, and recipient concentration.

Bound: [Q1 - 1.5×IQR, Q3 + 1.5×IQR]
Severity: (x - UpperBound) / IQR
Role: Serves as a deterministic baseline filter for extreme univariate outliers and sudden value leaps.
2. Isolation Forest (ML)
Weight: 50%

Trained using Scikit-Learn's IsolationForest on 9 standardized behavioral dimensions without label leakage. Isolates anomalous transactions by recursively partitioning features.

Features: [amt, dev, tx_1h, tx_24h, Δt, recip, dev_chg, loc_chg, hr]
Logistic Calibration: 1 / (1 + e^(14 × decision))
Role: Detects complex multivariate combinations (e.g. moderate amount + device change + 3 AM).
3. Time Series Velocity
Weight: 25%

Tracks rolling 6-hour baseline statistics and Z-scores for volume spikes. Flags short-term velocity anomalies: burst transactions in 1 hour and micro-interval drain attacks.

Z_score = (count - RollingMean) / RollingStd
Threshold: Z > 2.5 std deviations
Role: Catches sudden distributed bot bursts and carding attacks that evade static thresholds.
